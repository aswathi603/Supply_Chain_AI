# Abstract

The Intelligent Supply Chain Disruption Management Platform is an
AI-powered application that combines Streamlit, LangChain, LangGraph,
Ollama, and LangSmith to simplify supply chain disruption management.
The platform employs a Supervisor Agent to coordinate specialised agents
responsible for shipment tracking, inventory monitoring, supplier
management, recovery planning, reporting, forecasting, and Digital Twin
simulations. Human-in-the-Loop approval ensures that critical actions
remain under user control, while LangSmith provides workflow tracing and
evaluation.

# Chapter 1 -- Introduction

## Introduction

Modern supply chains are vulnerable to disruptions such as
transportation delays, supplier failures, inventory shortages, and
unexpected operational events. This project provides a unified
conversational platform where users interact with an AI assistant
instead of multiple disconnected systems.

## Problem Statement

Traditional supply chain management systems often require users to
switch between multiple applications. This project integrates these
capabilities into a single AI-powered platform.

## Objectives
