# API Documentation
All data access is via `api/*_api.py` which wraps `utils/json_loader.py`.
- `shipment_api.list_shipments()`
- `supplier_api.list_suppliers()`
- `inventory_api.list_inventory()`
- `warehouse_api.list_warehouses()`
- `order_api.list_orders()`
- `incident_api.list_incidents()`
- `transportation_api.list_modes()`
